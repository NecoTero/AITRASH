Рекомендация:

* JSONL или CSV — версионируемый источник нормализованных данных;
* SQLite — автоматически пересобираемый индекс для быстрого поиска;
* оригинальные PDF/XLSX/DOCX — доказательная база.

Не стоит начинать с векторной базы как с источника истины. Семантический поиск полезен для обнаружения похожих фрагментов, но точные требования, пользователи, версии и статусы лучше хранить как структурированные записи.
