# Подготовка планировок МКД2 для сайта

## Назначение

`presale_site_prepare.jsx` создаёт новые AI и PNG только внутри workspace.
Исходники из `Library` открываются без сохранения изменений. Каталог
`Коммерческие ОН` не входит в список пилота и рекурсивно не сканируется.

## Зафиксированный стандарт

- одна монтажная область `1200×1200 px`;
- PNG24 с прозрачностью и размером `1200×1200 px`;
- все доступные обводки до масштабирования нормализуются до `0.75 px`;
- JSX DOM Illustrator хранит геометрию в points; при `72 ppi`
  `1200 px = 1200 pt`, а `0.75 px = 0.75 pt`;
- геометрия, текст, мебель и положение всех объектов масштабируются вместе;
- в `PageItem.resize()` передаётся `changeLineWidths=100.0`;
- видимость, блокировка и порядок слоёв после операции должны совпадать
  с исходником;
- экшен `Сайт квартиры.aia` не запускается;
- варианты без мебели не создаются;
- существующие AI, PNG и отчёты не перезаписываются: при повторном запуске
  добавляется суффикс `_v2`, `_v3` и так далее.

## Выбор масштаба

Автоматически разрешены `100`, `110`, `120`, `150`, `170` и `200%`.
Сначала рассчитывается непрерывный коэффициент:

```text
s_raw = min(
  sqrt(777500 / (bbox_width × bbox_height)),
  1070 / max(bbox_width, bbox_height)
)
```

Затем выбирается ближайший к `s_raw` разрешённый дискретный коэффициент.
При точном равенстве выбирается меньший. Дополнительно скрипт запрещает
вариант, который вывел бы `visibleBounds` за `1200×1200 px`.

Константы явно заданы в `presale_site_config.json`:
`scale_area_constant_pt2: 777500` и `scale_max_side_target_pt: 1070`.

`140%` исключён из автоматического набора и допускается только записью в
`scale_overrides.csv`:

```csv
source_relpath,scale_percent,reason
Корпус 2.1/имя_файла.ai,140,Согласованное ручное исключение
```

## Запуск

1. Закрыть изменяемые документы Illustrator.
2. Проверить `presale_site_config.json` и `scale_overrides.csv`.
3. Запустить `presale_site_prepare.jsx` через Illustrator:
   `File → Scripts → Other Script`.
4. Проверить `09_outputs/_diagnostics/report.csv` и audit JSON.
5. Визуально сравнить новые PNG с исходными PNG-эталонами.

Для технического продолжения используются `start_index` и `max_files`.
Значение `max_files: 0` означает обработку всех записей, начиная с
`start_index`.

## Результаты

```text
09_outputs/
  _diagnostics/
    report.csv
    details/
      *_audit.json
  _pilot_wip/
    Корпус 2.1/
    Корпус 2.2/
    Корпус 2.3/
```

В `report.csv` записываются исходная монтажная область, `visibleBounds`,
слои, исходные и контрольные толщины обводок, рассчитанный и применённый
масштаб, финальные границы и пути результатов. Полные положения доступных
объектов до изменения сохраняются в соответствующем audit JSON.

В рабочем отчёте принимаются только строки со статусом `OK`. Строки
технических прогонов, признанные устаревшими после изменения правила,
сохраняются со статусом `OBSOLETE_WRONG_FORMULA`.

Если после масштабирования хотя бы одна обводка отличается от значения,
зафиксированного непосредственно перед масштабированием, строка получает
`ERROR`, а AI и PNG этого файла не сохраняются.

## Единицы документа и ручная проверка

Размеры в JSX остаются численно равны `1200` и `0.75`, потому что
Illustrator использует points, а для этого процесса `1 px = 1 pt`.
Значения нельзя переводить в миллиметры.

Чтобы вручную изменить единицы конкретного документа:

1. `Ctrl+R` — показать линейки.
2. Правый клик по линейке → `Пиксели`.
3. `Shift+O` — инструмент «Монтажная область».
4. Ввести в `W` и `H` именно `1200 px`.

Для новых документов можно дополнительно выбрать
`Редактирование → Установки → Единицы измерения` и установить
`Основные: Пиксели`, `Обводка: Пиксели`.

Текущий пилот геометрически имеет область `1200×1200 px` и PNG
`1200×1200 px`, но выходные AI унаследовали отображение единиц
`Millimeters` от исходников. В полном прогоне единицы AI считаются
исправленными только после повторного открытия файла и проверки
`document.rulerUnits === RulerUnits.Pixels`.

Полный готовый запрос для обработки всех 388 квартир и отдельной
проверки находится в `FULL_MKD2_INSTRUCTION.md`.
